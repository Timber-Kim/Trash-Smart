# 학습 결과 요약

## 실험 환경

- GPU: NVIDIA T4 (Google Colab)
- Dataset: AI Hub 한국형 재활용 쓰레기 분류 (15 classes, 40,196 images)
- Train/Val/Test: 32,157 / 4,019 / 4,020 (8:1:1, seed=42)
- Image size: 256px (longest side, aspect ratio 유지)
- Optimizer: SGD (momentum=0.9)
- Scheduler: StepLR (step_size=7, gamma=0.1)
- Epochs: 25
- Batch size: 32
- Learning rate: 0.001

### 데이터 증강 설정 (train only)

| 증강 기법 | 적용 여부 |
|-----------|-----------|
| RandomResizedCrop | ✅ |
| RandomHorizontalFlip | ✅ |
| RandomVerticalFlip | ❌ |
| RandomRotation (±15°) | ✅ |
| ColorJitter | ✅ |
| RandomGrayscale | ❌ |
| GaussianBlur | ❌ |

> val / test는 증강 없이 Resize → CenterCrop → Normalize만 적용

## 주요 관찰

- ResNet-50이 Test Acc 기준 4.28%p 더 높은 성능 (93.16% vs 88.88%)
- EfficientNet-B0는 파라미터 수 ~1/6 수준(4.0M vs 23.5M)이지만 에폭 12 이후 plateau — 모델 용량의 한계로 추정
- ResNet-50은 에폭 7(LR 0.001 → 0.0001 drop) 이후 val Acc가 꾸준히 상승
- 학습 시간은 EfficientNet-B0가 36% 짧음 (91분 vs 143분)
- 추론 속도는 EfficientNet-B0가 약 2배 빠름 (1.31ms vs 2.57ms, GPU 기준)
- 두 모델 모두 PP, PS, colored(플라스틱 계열) 클래스에서 상대적으로 낮은 F1 점수
